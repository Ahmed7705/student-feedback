# Online Bookstore (COMP-315 Project 2)

Features:
- Book Catalog with search, category filter, and JavaScript total price calculator
- Add Book form with Reset button, price/quantity validation, and optional cover upload
- Manage Books table with quantity display, Edit, and Delete with confirmation
- Session login, registration, and logout (Test account: admin@bookstore.com / 123456)

Database Tables:
- users (id, name, email, password)
- books (id, title, author, category, price, quantity, image_path)

Hosting on InfinityFree / XAMPP:
1. Import database.sql in phpMyAdmin.
2. Check database details in config.php.
3. Upload files to htdocs/.
