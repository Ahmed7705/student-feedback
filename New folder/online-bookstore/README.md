## Project Structure:
- `online-bookstore-php/`: Core project developed in Plain PHP with MySQL PDO (runs on port `8085`).
- `online-bookstore-laravel/`: Laravel version developed with MVC architecture (runs on port `8084`).
- `PROJECT_REPORT.md`: Comprehensive project report with team contributions, database design, and setup guide.
- `online_bookstore_php.zip`: Ready-to-deploy archive for web hosting (InfinityFree / XAMPP).
- `online_bookstore_laravel.zip`: Complete Laravel application archive.

## Core Features:
- Book catalog with search, category filtering, and JavaScript price calculator.
- Add and edit book forms with complete validation and file uploads.
- Inventory management table with stock status and delete confirmation.
- User authentication and role-based access control (Admin vs Customer).
- MySQL database schema with prepared statements and secure password hashing.
