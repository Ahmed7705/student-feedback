Features:

- Course filter and search
- Session login, registration, and logout (Test account: maryam@jazanu.edu.sa / 123456)
- Image upload stored in uploads/

Hosting on InfinityFree / XAMPP:
1. Import database.sql in phpMyAdmin.
2. In config.php, set $use_mysql = true; and add your MySQL details.
3. Upload files to htdocs/.
